# Sextante

Observatorio municipal B2C: reserva **un telescopio exclusivo** por franja, arma una lista de **objetos visibles esa noche** (no un catálogo genérico) y entra con **ticket QR**.

- Frontend: Angular 22 (signals, zoneless)
- Backend: NestJS 11 + TypeORM + SQLite (Neon-ready)
- Puerto API: **3073**
- Demo: `demo@sextante.dev` / `demo1234` · staff: `staff@sextante.dev` / `demo1234`

El cielo no se inventa. Se calcula.
